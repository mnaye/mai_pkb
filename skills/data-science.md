# Research Skill — Data Science

A focused source guide for the `data-science/` area. The weekly brief loads this when researching data science.

## Goal

Surface the most notable **new** data-science work from the past 7 days — methods, techniques, tooling, and applied work. Favor two kinds of signal:

1. **High-star GitHub repositories** — new or fast-rising libraries and tools for data analysis, ML, feature engineering, experimentation, visualization, and MLOps.
2. **Published articles & papers** — techniques and applied case studies from research venues and strong engineering blogs.

## How to research

### GitHub (high-star repos)

1. Check **GitHub Trending** (https://github.com/trending, `?since=weekly`) and **star-sorted search**:
   - https://github.com/search?q=data+science&type=repositories&s=stars&o=desc
   - https://github.com/search?q=machine+learning+library&type=repositories&s=stars&o=desc
   - queries: `dataframe`, `feature engineering`, `time series`, `data visualization`, `experiment tracking`, `MLOps`, `causal inference`.
2. **Fetch each repo page** for the real name, description, star count, and last-updated date.
3. Favor repos with **1k+ stars** or clear fast risers this week; note the star count.

### Articles & papers

Fetch recent, citable pieces:
- **arXiv** — https://arxiv.org/list/stat.ML/recent and https://arxiv.org/list/cs.LG/recent
- **Papers with Code** — https://paperswithcode.com
- **KDnuggets** — https://www.kdnuggets.com
- **Towards Data Science** — https://towardsdatascience.com
- **Google / Netflix / Uber / Meta engineering blogs** — applied DS case studies
- **Kaggle blog / competitions** — https://www.kaggle.com/blog

## Priority sources

- **GitHub** — Trending + star-sorted repository search
- **arXiv** (stat.ML, cs.LG), **Papers with Code**
- **KDnuggets**, **Towards Data Science**, **Kaggle**
- Company engineering blogs (Netflix, Uber, Meta, Google, Spotify) for applied work

## What to capture per item

- **Name / repo / title** (bold)
- One-line description — what it is and why it matters
- **Star count** (for repos) and **date**
- **Link** to the fetched source

## Guardrails

- **Only include repos/articles you actually fetched** — real star counts, real links, no fabrication.
- For repos, verify recent activity (pushed within ~a week) so the list is current.
- Prefer primary sources (repo, paper, official blog) over roundups.
- Attribute curation to **Mai with Claude**.
