- **[openai/codex-security](https://github.com/openai/codex-security)** `topic:agents`. GitHub repo, **~13.7k stars, +2,294 this week** (GitHub Trending, weekly view, read 2026-11-16). Apache-2.0. "OpenAI's Codex Security CLI and TypeScript SDK for finding, validating, and fixing security vulnerabilities."
  - **What it does:** scans a repo, selected paths or Git changes (Standard and Deep modes), validates candidate findings, generates patches, drafts `SECURITY.md` and threat models, and exports SARIF, JSON and CSV. It can track findings in Linear, Jira or GitHub.
  - **How it runs:** local CLI (`cs scan .`), Codex plugin, SDK, or GitHub Action. "Cloud is an optional connection; local scans work without it." Providers include OpenAI, Amazon Bedrock, OpenRouter and Fireworks AI.
  - **Cost control:** the Action example sets an estimated $5 limit per scan, but "Requests in progress can exceed the limit."

## So what

*For healthcare data scientists, ML engineers in healthcare, and healthcare executives.*

- **Healthcare data scientists:** **Claude Fable 5.2** costs $8 per million tokens (small chunks of text) going in and $40 per million coming out. Anthropic's own tests say it beats its last top model on coding and reasoning. Those are the maker's numbers. Test it on your own de-identified tasks before you switch.
- **ML engineers in healthcare:** By default, Anthropic keeps **Fable 5.2** data for 30 days for safety checks. Zero data retention is in private beta only. Don't send private health data (PHI) until your legal team confirms your contract covers this. **openai/codex-security** can scan code on your own machine with no cloud link. That fits code that sits near patient data. It still sends code to the model provider you pick, so choose one your security team has approved. Its SARIF output plugs into most code-scanning dashboards.
- **Healthcare executives:** Both tools push AI into security work. Mythos 5.2 is only for groups that pass Anthropic's checks. Ask your security lead whether to apply. Budget for scan costs: the codex-security GitHub example caps a scan at about $5, but a scan can run over that cap.

### Problems worth taking on

**AI security scan of your patient-data code.** *Problem:* Code that touches patient records gets few security reviews, and a breach costs far more than a review. *Why now:* **openai/codex-security** scans locally, checks its own findings, and suggests fixes. *First step:* Pick one internal repo with no real patient data in it. Have the AppSec lead run a Deep scan with an approved model provider. Success is the share of findings your team agrees are real, and the cost per scan.
