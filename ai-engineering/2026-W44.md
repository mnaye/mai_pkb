*Week of 26 October 2026 (ISO week 44). Curated by Mai with Claude.*

## The week in one paragraph

The week's theme is agents that check their own work and ask before they act. **`cloudflare/security-audit-skill`**, Cloudflare's MIT-licensed skill that turns a coding agent into a security auditor, gained about **15,000 stars** this week, the most on GitHub's weekly board. Its design is the point: the agent that confirms a finding is never the agent that found it. On **21 October**, Anthropic launched **Claude Duet** as a research preview. Duet is an always-on agent that watches connected apps, works in its own cloud browser, and asks for approval before sending, paying, signing or deleting. Coding-agent fleet managers (`stablyai/orca`) and harnesses (`ruvnet/ruflo`, `anomalyco/opencode`) also kept climbing. Several model updates showed up only on third-party trackers and were not confirmed (see Also noted).

## Items

- **[cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)** `topic:skills-tooling`: "A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings." **48.1k ★, +15,072 this week** (#1 on GitHub's weekly trending board), MIT license, 14 commits. It needs a coding agent whose model supports tool use and **parallel sub-agents**, plus Node.js and an **OS-enforced sandbox** for running target code. Install with `npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit`. **Six phases:** reconnaissance (architecture, trust boundaries and a `coverage-ledger.json`), coverage-led hunting by isolated agents, a fresh verifier that tries to **disprove** each candidate, schema-checked `findings.json` (`confirmed` / `needs_validation` / `rejected`), a second check of the final records by fresh agents, then reporting. README: "The agent that checks a finding is never the agent that found it." The only number it gives is about coverage: "a single run found roughly half of the vulnerabilities that repeated runs found in total." It describes itself as the starting point for Cloudflare's internal vulnerability-discovery harness. *Repo page and weekly trending board fetched 2026-10-26. The README gives no false-positive rate.*

- **[Claude Duet](https://macrumors.com/2026/10/21/anthropic-claude-duet/)** `topic:agents`: Anthropic's proactive background agent, launched **21 October 2026** as a **research preview** (MacRumors). It is built on **Claude Opus 5.5**. It sends a morning brief, checks connected apps every few hours, and runs on **its own cloud virtual machine with its own browser**. It asks for approval before **sending a message, making a payment, signing a document or deleting a file**. It doesn't see passwords or logins when given account access, and a dedicated classifier checks messages for sensitive-data leaks. **Access:** waitlist only, **US Pro and Max subscribers**, web and a standalone iOS app. Background checks count against plan limits. Other coverage says Team and Enterprise plans are not included yet, and Anthropic says Duet can misjudge urgency. Anthropic's announcement is at [claude.com](https://claude.com/resources/articles/claude-duet). *MacRumors article fetched 2026-10-26. Anthropic's own page was not read.*

## So what

*For healthcare data scientists, ML engineers in healthcare, and healthcare executives.*

- **Healthcare data scientists:** **security-audit-skill** uses one agent to find a problem and a separate agent to try to disprove it. You can borrow that pattern for any AI that labels charts or pulls facts from notes. Have a second model try to disprove each answer, and count how often it wins. Also note Cloudflare's own warning: one run found only about half the bugs that several runs found. Run more than once.
- **ML engineers in healthcare:** Try **security-audit-skill** on one internal service that touches private health data (the law calls it PHI). Run it in a sandbox, as the README requires, and never on live patient systems. Treat its output as leads for your security team, not a pass or fail. Claude **Duet** runs in its own cloud browser and logs into your accounts. Don't connect accounts that hold patient data to a consumer preview.
- **Healthcare executives:** A free, open-source security check now exists for code your teams write with AI. It is MIT licensed. Ask your security lead to test it against your last outside audit. See whether it finds the same issues. For **Claude Duet**, set a clear rule now. Staff should not link work email or clinical apps to personal AI agents. Business plans aren't included in the preview yet.

### Problems worth taking on

**Re-run last year's security audit with an agent.** *Problem:* Outside security audits of in-house health apps are slow and costly, so most code ships between audits without review. *Why now:* **cloudflare/security-audit-skill** gives a free, structured audit with a separate checking step and machine-readable findings. *First step:* Have one ML or security engineer run it three times, in a sandbox, on a repo your last outside audit covered. Compare its confirmed findings to that audit's report. Success is catching most of the audit's real issues, with few false alarms your team has to clear.
