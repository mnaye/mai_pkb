# AI Engineering — 2026-W36

*Week of 31 August 2026 (ISO week 36). Curated by Mai with Claude.*

## The week in one paragraph

Last week the story was the agent harness becoming a **plugin platform**. This week the same energy moved one layer up: what actually trended was **agent skills** — narrow, packaged capabilities that any harness can load. [`tt-a1i/archify`](https://github.com/tt-a1i/archify) went from nowhere to **37.7k stars (+18,103 this week)** by doing one thing — turning a codebase description into a verifiable architecture diagram — and shipping it as a skill Cursor and Claude Code can call directly. [`K-Dense-AI/scientific-agent-skills`](https://github.com/K-Dense-AI/scientific-agent-skills) (**40.5k stars, +4,309**) is the same shape aimed at research workflows. Underneath, [`apache/maka`](https://github.com/apache/maka) — now an ASF incubating project — is arguing the opposite case: that the durable, auditable **runtime** is the thing worth standardizing, not the extensions. Nothing new landed in the productionizing-healthcare-models track inside the 7-day window.

## Items

- **[tt-a1i/archify](https://github.com/tt-a1i/archify)** — a Node.js rendering system that compiles a code description into typed JSON, then into self-contained HTML/SVG across five diagram types (architecture, workflow, sequence, data flow, lifecycle), with built-in validation so the diagram is checkable rather than vibes. Packaged as an **agent skill** for Cursor and Claude Code, so the diagram is generated in-chat. **37.7k stars, +18,103 this week** — by a wide margin the fastest riser on the weekly trending list. Stable release **v2.16.0 on 2026-08-30**, 208 commits. *Fetched 2026-08-31.*

- **[apache/maka](https://github.com/apache/maka)** — "a local-first AI agent workspace," now incubating at the **Apache Software Foundation** under Apache-2.0. Sessions and execution records stay on the machine; model messages, tool calls, results, and decisions are written to a **durable append-only log**, which is what enables crash recovery and session branching. Three front-ends — Electron/React desktop, terminal CLI, and evaluation tooling — all route through one Runtime Host, so benchmarks and interactive use exercise the same execution path. **4.3k stars, +1,973 this week**; no official ASF release yet. The interesting bet here is governance: a vendor-neutral foundation home for agent runtime plumbing, against a field where every harness ships its own. *Fetched 2026-08-31.*

- **Anthropic's plugin registries kept compounding.** [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) is at **3,020 stars, +2,162 this week** — up from 1,140 / +406 in W35, so the weekly gain itself more than quintupled — and the first-party [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) trended alongside it at **35,714 stars, +1,940**. Two consecutive weeks of acceleration on the same registry is the signal worth tracking; last week's open question (do these converge on MCP as the wire format, or fragment into per-harness extension APIs?) is still open. *Source: [GitHub Trending, weekly](https://github.com/trending?since=weekly), fetched 2026-08-31.*
