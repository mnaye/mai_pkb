# AI Engineering — 2026-W35

*Week of 24–30 August 2026. Curated by Mai with Claude.*

## The week in one paragraph

The agent harness became a **plugin platform** this week. DeepSeek's open-source [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) — tagline *"Everything is a Plugin"* — is the loudest example, sitting at **190.2k stars** and MIT-licensed while still labelled a developer preview. The tell that this is a pattern rather than one repo: the meta-framework it is built on, [cordis](https://github.com/cordiverse/cordis), rode into the weekly trending list on its coattails (**+2,725 stars**), and two vendor plugin registries — [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) and [cursor/plugins](https://github.com/cursor/plugins) — climbed alongside it. Where last week's momentum was about what an agent *remembers* ([OpenViking](https://github.com/volcengine/OpenViking) is still trending, now **32.7k stars, +3,799**), this week's is about what an agent can be *extended with*, and who owns the registry that extension ships through. Nothing new landed in the productionizing-healthcare-models track inside the 7-day window.

## Items

- **[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)** — DeepSeek's own agent harness, architected so that every capability is a plugin, on top of the Cordis composition framework. Ships a local web UI (`npm`, serves at `127.0.0.1:3080`), **MIT-licensed**, ~13,100 commits on `master`. **190.2k stars** at time of fetch, and openly flagged as a developer preview with breaking changes expected — the star count is running well ahead of the maturity. Notable less for the harness itself than for a frontier lab publishing its agent scaffolding under a permissive license and a plugin contract. *Fetched 2026-08-24.*

- **[cordiverse/cordis](https://github.com/cordiverse/cordis)** — "Meta-Framework of Spatiotemporal Composability," the plugin/lifecycle substrate underneath deepseek-harness. **7,331 stars, +2,725 this week** — the fastest relative climb among the week's agent-infrastructure repos, and a decent proxy for how much of the harness gold rush is actually landing on shared plumbing rather than each vendor rebuilding it. *Source: [GitHub Trending, weekly](https://github.com/trending?since=weekly), fetched 2026-08-24.*

- **Plugin registries are consolidating around vendors.** [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) (**1,140 stars, +406 this week** — up from 751 last week) and [cursor/plugins](https://github.com/cursor/plugins) (**4,866 stars, +1,761**) both trended in the same weekly list. Two of the three big coding-agent vendors now run a first-party plugin spec and marketplace; the open question for anyone building agent tooling is whether these converge on MCP as the wire format or fragment into per-harness extension APIs. *Source: [GitHub Trending, weekly](https://github.com/trending?since=weekly), fetched 2026-08-24.*
