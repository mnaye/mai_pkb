*Week of 21 September 2026 (ISO week 39). Curated by Mai with Claude.*

## The week in one paragraph

No frontier model landed inside this window, and the two things that moved hardest both attack the same problem from opposite ends: **what you can run, and what you can trust**. **`JustVugg/colibri`** — a dependency-free C inference engine that treats VRAM, RAM and NVMe as one memory hierarchy and streams MoE experts off disk — appeared on the weekly board at **36,739 ★ (+7,441)** claiming to decode Kimi K3 (2.8T) and GLM-5.2 (744B) class models on desktops, including CPU-only boxes. **`cloudflare/security-audit-skill`** took the single largest weekly gain on the board, **+14,864 to 18,717 ★**, for a skill whose central idea is that the agent will hallucinate and must therefore prove every finding to a *different* agent. That is the skills-bundle wave this KB has tracked since W36 maturing from prompt-shaping into verification architecture — and it is notable that both of this week's items are vendor- or systems-engineering work rather than another prompt pack. Track 2 (productionizing healthcare models) produced nothing datable to this window for the **fourth consecutive week**.

## Items

- **[cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)** — "A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings." **18,717 ★, +14,864 this week** — the largest weekly gain on the trending board by a wide margin, and roughly a **4× jump** in total stars in seven days. The repo is not new (initial commit **18 June 2026**, by `literally-dan`); what happened this week is that it was found, on the back of continued commits through **14 September** ("Clarify guidance and full audit modes", plus workflow hardening). The design is the reason to care: a six-phase pipeline — recon maps architecture and trust boundaries, isolated hunt agents attack from separate angles (injection, access control, business logic, crypto, feature abuse, chained attacks, plus a wildcard), then **candidate findings go to validation agents that try to disprove them, and the agent that checks a finding is never the agent that found it**. Findings land as `confirmed` (with a complete source trace), `needs_validation`, or `rejected`. Install is one line via the Skills CLI (`npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit`); it requires a model with tool use and parallel subagents, Node.js, and an OS-enforced sandbox. Adversarial self-verification as a packaged, installable artifact is a more transferable idea than the security content itself. *Repo page and commit history fetched 2026-09-21; star delta from the weekly trending page, same date.*

- **[JustVugg/colibri](https://github.com/JustVugg/colibri)** — "Run frontier MoE models on existing hardware in pure C." **36,739 ★ (+7,441 this week)**, 3.9k forks, zero external dependencies. It treats **VRAM, RAM and NVMe as a single multi-tier hierarchy**, streaming routed experts from disk on demand instead of requiring full model residency — so the constraint becomes storage bandwidth rather than accelerator memory. Nine model families are listed as supported, including **Kimi K3 (2.8T)**, **Inkling (975B)**, **GLM-5.2/5.3 (744B/419B)**, GLM-5.3-Flash (321B, vision), DeepSeek V4 variants, Qwen 3.8-Flash-Next / 3.6, and OLMoE (7B). The README's measured decode figures are honest about the trade: **5.8–6.8 tok/s on 6× RTX 5090 at full residency**, **~1.8 tok/s warm on a 128 GB CPU-only desktop**, **1.07 tok/s on a single RTX 5070 Ti**, and **0.05–0.1 tok/s on a 25 GB dev box** — i.e. it buys *feasibility*, not speed. Supporting techniques: per-layer LRU cache with learned hot-store pinning, batched expert unions overlapping disk reads with compute, a claimed **57× smaller MLA KV state**, speculative decoding via a native MTP head, dual-SSD striping, and token-exact forward validation against a transformers oracle. Optional CUDA / Metal / Vulkan backends. *Repo page fetched 2026-09-21; figures as the README states them, not independently benchmarked.*
